# Vellora Studio — Site institucional

Landing page responsiva para apresentar e comercializar templates, desenvolvimento de landing pages, personalização de sites e manutenção mensal.

## Tecnologias
- HTML5 semântico
- CSS3 responsivo
- JavaScript puro para menu móvel, ano automático e preparação de contato por e-mail

## Como visualizar
Abra `index.html` no navegador. Para publicar, envie os arquivos do projeto para um repositório GitHub conectado à Vercel.

## Formulário
O formulário abre o aplicativo de e-mail do visitante com a mensagem preenchida. Para receber contatos sem depender do e-mail local, conecte um serviço de formulários ou backend.

## Estrutura
- `index.html`: estrutura e conteúdo
- `style.css`: identidade visual e responsividade
- `script.js`: menu e formulário
- Imagens: exemplos visuais do portfólio
